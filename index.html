Tentang Marmoot OS

Apa itu Marmoot OS?

Marmoot OS adalah distribusi Linux yang dirancang khusus untuk mahasiswa informatika dan calon software engineer. Berbasis OpenEuler 24.03 LTS dengan desktop environment X11/GNOME 45, sistem operasi ini hadir dengan filosofi "plug and play" - install dan langsung bisa digunakan untuk belajar, coding, dan bereksperimen.

Mengapa Memilih Marmoot OS?

Sebagai mahasiswa informatika, waktu adalah aset berharga. Daripada menghabiskan berjam-jam mengkonfigurasi sistem, menginstall tools satu per satu, dan troubleshooting berbagai dependency issues, Marmoot OS memberikan environment yang sudah siap pakai. Fokuskan energi kamu untuk belajar konsep, menulis code, dan membangun project—bukan mengatur sistem operasi.

Siapa Developer-nya?

Marmoot OS dikembangkan oleh MARMOOT TEAM PROJECT, sebuah tim developer yang memahami tantangan mahasiswa informatika dalam mempersiapkan environment development. Dengan pengalaman dalam system engineering dan software development, tim ini berkomitmen untuk terus mengembangkan dan menyempurnakan Marmoot OS.

Spesifikasi Sistem

  • Base System: openEuler 24.03 LTS
  • Kernel: Linux 6.6.0-119
  • Desktop: X11 / GNOME 45
  • Version: 24.11 (LTS)
  • Architecture: x86_64

Minimum Requirements

  • RAM: 4 GB (8 GB recommended)
  • Storage: 25 GB available space
  • Processor: 64-bit dual-core processor
  • Graphics: Graphics card with OpenGL 3.3 support
